# Leerlauf

Neun Werkzeuge, die nichts von dir wollen. Eine Datei, läuft offline, alles bleibt auf deinem Gerät.

**[▶ Öffnen](https://raw.githack.com/raphaelgeil652-lab/business/claude/alltags-tools-situation-kma4qf/alltag/leerlauf/index.html)**

## Die neun Räume

| Raum | Was passiert |
|---|---|
| **Eine Frage am Tag** | Jeden Tag eine Frage, die man nicht in zwei Sekunden beantwortet. Du schreibst was hin oder lässt es. Nach Wochen hast du ein Tagebuch, ohne je eins geführt zu haben. 52 Fragen, jede kommt frühestens nach zwei Monaten wieder. |
| **Der Gedankenparkplatz** | Der Gedanke, der im Kreis läuft, kommt rein und ist weg — du siehst ihn nicht mehr. Nach 14 Tagen fragt die Seite einmal: noch ein Thema? Danach steht da, wie viele sich von selbst erledigt haben. |
| **Der Umweg** | Eine ausgewürfelte Regel zum Loslaufen (Dauer, Regel, eine Sache zum Achten). Kein Ziel, keine Karte. |
| **Die Seite, die du wegwirfst** | Freies Schreiben. Am Ende **Behalten** oder **Vergessen** — Vergessen löst den Text sichtbar auf und er ist wirklich weg. |
| **Fenster** | Ein Timer, der nichts tut. Nach vier Sekunden verblasst die ganze Oberfläche, der Bildschirm wird leer. Tippen holt sie zurück. |
| **Die Münze, die dich durchschaut** | Wirf sie — und bevor das Ergebnis kommt, fragt sie, was du dir insgeheim gewünscht hast. Danach ist das Ergebnis egal. |
| **Brief an dich** | Text schreiben, Öffnungsdatum wählen (3 Monate bis 3 Jahre). Bis dahin zu. Kein Ton, keine Erinnerung — er liegt einfach da. |
| **Das Jahr auf einer Seite** | 365 Kästchen. Pro Tag ein Wort und eine Farbe, mehr geht nicht. Zukünftige Tage sind gesperrt. |
| **Der Stups** | Eine kleine analoge Sache für heute („Heute ein Weg ohne Kopfhörer"). 30 Stück, fragt nie nach. |

## Die Regeln, nach denen das gebaut ist

- **Keine Serien, keine Streaks, keine roten Punkte.** Sobald dich so ein Ding zu etwas drängt, ist es genau das geworden, wovor du weg wolltest.
- **Nichts erinnert dich.** Keine Benachrichtigungen, keine Mails, kein Ton. Du kommst, wenn du kommst.
- **Nichts wird ausgewertet.** Keine Statistik, keine Diagramme, keine Bewertung deiner Antworten. Einzige Ausnahme: der Parkplatz zählt, wie viele Gedanken sich erledigt haben — und genau das ist dort der Witz.
- **Alles bleibt hier.** `localStorage`, Schlüssel `leerlauf-v1`. Kein Konto, kein Server, keine Schrift und keine Bibliothek von außen. Eine Datei, 44 KB.

Die Kehrseite: **leerst du die Browserdaten, ist alles weg**, und auf einem zweiten Gerät fängst du bei null an. Im privaten Fenster sagt die Seite dir, dass nichts gespeichert wird.

## Ändern

Die Inhalte stehen oben in der Datei in Listen: `FRAGEN`, `STUPSE`, `UMWEG`, `RAEUME`.
Da kannst du Fragen rauswerfen oder eigene dazuschreiben, ohne den Rest anzufassen.
